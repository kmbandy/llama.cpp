### Phase G.6 — perf (a-h)
- **a**: BLOCK-config sweep via `tune_gemm_ml8.py` (Python kernel benchmarking; ~30 configs/shape per shape×tier)
- **b**: tuned configs threaded through C++ wrapper, M-tier-aware cache key
- **c**: rocprofv3 trace identified rotation as 92.2% of GPU time
- **f**: rotation kernel rewritten as row-wise FWHT (existing `mt_turbo_fp8_fwht`) + small per-token H_a^T multiply → **26× total prefill speedup** vs Phase-A starting point
- **g**: PPL drift root-cause hunt — one-character bug in `ml8_fp32_to_e4m3` overflow check (`e_out >= 15` → `e_out > 15`). +0.40 PPL of drift in HIP path collapsed to noise
- **h**: M=1 GEMV kernel with 4-dimensional sweep (BN × K_COOP × LDS × LAYOUT, 68 legal configs). Winner: BN=16, K_COOP=8, LDS=0, LAYOUT=0 → 30.66 t/s decode

## Open matrices — GEMV decode optimization

Decode is at **60% of f16** (30.66 vs 50.89 t/s). M2/M3 work to close.

### M2 — non-config levers (next sweep)
| # | Lever | Domain | Effort | Expected |
|---|---|---|---|---|
| A | fp8→fp32 conversion | software (current) / 16-entry fp32 LUT precomputed per K-group / `__hip_cvt_*_fp8x2` HW intrinsic | low-med | 3-5% |
| B | `b_pack` load width | byte (current) / uint16 / uint32 / uint128 | med (alignment) | 10-20% (memory-side win) |
| C | `a[k]` load width | scalar (current) / float4 | low | small |
| D | `__ldg` explicit cache hints | with / without | trivial | small |
| E | LDS bank-conflict-free partial layout | current `s_partial[BN][K_COOP]` may conflict at LDS_A=0 | low | small |

### M3 — architectural variants
| # | Lever | Description |
|---|---|---|
| α | wvSplitK_hf-style 32-lane wave-cooperative K-split | vLLM `csrc/rocm/skinny_gemms.cu` pattern, DPP reduce within wave |
| β | Layered K-tiling with prefetch double-buffer | overlap memory with compute |
| γ | Fused dequant prologue | inline LUT in Triton style — eliminates per-iter conversion calls |

**Target:** close the 1.66× remaining gap to f16 50.89 t/s. M2-B alone (uint32 loads) is the most promising single lever; M3-α is the biggest structural change.
